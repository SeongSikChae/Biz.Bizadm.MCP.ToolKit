# D01_02 값 목록 입력의 대소문자

## 상황

스펙 검토 1회차 지적 5. 관련 항목: `C01-I1`·`C01-I3`·`C01-I4`의 `state`, `C01-I1`의 `sort`·`direction`. 검토 의견: 대소문자를 구분하지 않고 비교해 소문자로 보낸다는 규칙이 `C01-I1`의 `state`에만 붙어 있고 나머지 값 목록 입력은 정하지 않아, `Closed`·`DESC` 같은 입력을 받을지 거부할지가 Tool마다 다르게 구현될 수 있으며 판정할 수용 기준도 없다.

## 결정

- 값 목록 입력(`state`·`sort`·`direction`)은 공백을 뗀 뒤 계약에 적힌 소문자 값과 정확히 같아야 한다. 대문자가 섞이면 목록 밖 값으로 보고 `... must be one of: ...` 오류를 낸다. 대문자가 섞인 입력을 거부하는지는 `R01-A13`이 확인한다.
