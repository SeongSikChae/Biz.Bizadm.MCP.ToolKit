# D01_03 R01-A4 확인 시점

## 상황

`T01_01` 검증(`V01_01`)에서 `R01-A4`(배포된 MCP 서버로 실제 저장소에 마감일 있는 마일스톤을 만들어 응답과 웹 화면의 마감일을 확인)가 미확인으로 남았다. 새 버전이 배포된 Bizadm MCP 서버가 없고, 실제 저장소 쓰기에는 사용자 승인이 필요하다. 이 기준을 어떻게 처리할지 정해야 했다. 관련 항목: `R01-R3`, `R01-A4`, `C01-I3`.

## 결정

- `T01_01`을 "진행"으로 둔 채 지금 변경을 커밋하고, 새 버전을 배포한 뒤 `R01-A4`를 확인해 `V01_01` 차수를 올린다. 그때 `R01-R3`·`C01-I3`을 반영하고 `T01_01`을 "끝남"으로 바꾼다.

## 이유

- 사용자가 말하지 않음
