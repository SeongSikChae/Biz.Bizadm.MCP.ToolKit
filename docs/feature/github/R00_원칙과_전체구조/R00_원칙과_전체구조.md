# R00 원칙과 전체구조

## 목적

등록한 GitHub 인스턴스로 저장소 작업을 MCP Tool로 처리한다. GitHub MCP Server를 중계하는 Tool(`github_list_instances`, `github_list_tools`, `github_call_tool`)을 기본으로 쓰고, GitHub MCP Server가 노출하지 않는 기능만 GitHub REST API를 직접 부르는 Tool로 채운다.

## 스펙 목록

| 번호 | 제목 | 요약 |
| --- | --- | --- |
| `R01` | 마일스톤 관리 | 저장소 마일스톤을 조회·생성·수정·삭제하는 REST Tool |

## 기존 문서

이 규칙 이전 형식의 GitHub 문서는 `docs/github/`(0001~0011)에 있다. 중계·태그·ref·릴리스·rate limit Tool의 방안·설계·개발 기록이며 고치지 않는다.
